# Yatъ

Текстовый редактор для веба (в разработке). Текущая реализация — **Telegram-бот**: анализирует текст, находит бан-слова и их формы, а также гибридно исправляет опечатки, грамматику и пунктуацию.

Ядро (`backend/app/analyzer`) **клиент-агностик**: не зависит от Telegram и пригодно для будущего веб-редактора.

## Возможности

**Анализ и подсветка банвордов**
- Находит целевые слова из бан-листа во всех падежах и числах (нейронка, нейронки, нейронкой)
- Выделяет найденные слова *курсивом* прямо в Telegram
- Считает статистику (всего / уникальных) — отдельным сообщением
- Не цепляет «похожие по корню» слова (нейросети ≠ нейронка)

**Гибридная коррекция текста**
- Алгоритмический этап (бесплатно, без сети): исправляет явные опечатки при единственном однозначном варианте, ставит пробел после `, ; : ! ?`, схлопывает двойные пробелы, поднимает заглавную после точки. Бан-слова и имена собственные не трогает
- Глубокий этап (опционально, через `/correct`): Yandex GPT исправляет грамматику и пунктуацию с минимальными правками
- Кэш результата по хэшу текста — повторная отправка того же текста не вызывает нейросеть

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и клавиатура |
| `/help` | Справка |
| `/words` | Список бан-слов |
| `/correct` | Включить/выключить глубокую правку (грамматика, пунктуация) |

## Пример работы

**Сообщение:**
```
Современные нейронки используют сложные алгоритмы,но есть один ньюанс.
```

**Ответ (глубокая правка включена):**
```
Современные _нейронки_ используют сложные алгоритмы, но есть один нюанс.

📊 Статистика:
• нейронка: 1

Всего найдено: 1 слов
Уникальных слов: 1
```

## Архитектура

```
Пользователь (Telegram)
        │
        ▼
  app/bot/handlers.py   ← команды, кнопки, текст, длина
        │
        ▼
  app/analyzer/corrector.py  ← алгоритм → (опционально) LLM → результат
        │
        ├──► AlgorithmicCorrector  (опечатки, оформление, кэш слов)
        │
        └──► llm_yandex.py  (Yandex GPT, кэш по хэшу текста)
        │
        ▼
  app/analyzer/analyzer.py  ← морфология, подсветка банвордов, статистика
        │
        ▼
  Ответ в чат (Markdown) + отдельное сообщение со статистикой
```

Слой коррекции (`corrector.py`, `llm_yandex.py`) ничего не знает о Telegram — это самостоятельное ядро, которое можно звать из любого клиента.

## Установка и запуск

1. Создайте и активируйте виртуальное окружение, установите зависимости:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r backend/requirements.txt
   ```

2. Создайте `.env` в корне проекта:

   ```bash
   TELEGRAM_TOKEN=ваш_токен_от_BotFather
   YANDEX_CLOUD_FOLDER=ваш_cloud_folder_id
   YANDEX_CLOUD_API_KEY=ваш_api_key_из_AI_Studio
   YANDEX_CLOUD_MODEL=yandexgpt-lite/latest
   ```

   Ключи Yandex необязательны для запуска: без них бот работает, но глубокая правка будет помечаться как «недоступна».

3. Запустите бота:

   ```bash
   cd backend/app
   PYTHONPATH="$PWD:$PWD/bot" ../../.venv/bin/python bot/bot.py
   ```

   Важно: импорты плоские (`from handlers import ...`, `from config.config import ...`), поэтому на `PYTHONPATH` должны быть и `backend/app`, и `backend/app/bot`. В Docker это настроено через `PYTHONPATH=/app/app`.

## Настройка

- **Бан-слова** — `TARGET_WORDS` в `backend/app/config/config.py`. Для слов, которые pymorphy3 «ломает», правится словарь лемм `WORDS_LEMMA`.
- **Лимиты** — `MAX_TEXT_LENGTH` (максимум длины сообщения), `DEEP_CORRECT_MAX_LENGTH` (порог для глубокой правки), `DEFAULT_DEEP_CORRECT` (дефолт переключателя `/correct`).
- **Подробности о потоке и модулях** — см. [`docs/FLOW.md`](docs/FLOW.md).
