# Yatъ

Текстовый редактор для веба: выделяет банворды, поддерживает Markdown и использует нейронки для редактуры.

## 📋 Что умеет бот v1.0

✅ **Анализирует текст** - находит целевые слова и их формы  
✅ **Выделяет слова _курсивом_** - показывает результат прямо в Telegram  
✅ **Работает с морфологией** - ищет все падежи и формы (нейронка, нейронки, нейронкой)  
✅ **Показывает статистику** (пока отключено) - сколько и каких слов найдено  
✅ **Игнорирует схожие слова** - "нейросети" ≠ "нейронка"  

## 🎯 Пример работы

**Сообщение:**
```
Современные нейронки используют сложные алгоритмы. 
Нейронка - это мощный инструмент для разработки.
```

**Ответ от бота:**
```
Современные **нейронки** используют сложные **алгоритмы**. 
**Нейронка** - это мощный инструмент для разработки.

📊 Статистика:
• нейронка: 2
• алгоритм: 1

Всего найдено: 3 слов
Уникальных слов: 2
```

## Архитектура

### Как устроено сейчас

Бэкенд — это один Telegram-бот на **python-telegram-bot**. Пользователь пишет в чат; бот получает обновление, обработчик из пакета `bot` читает текст (или подпись к медиа), передаёт строку в анализатор из пакета `analyzer`, затем отправляет ответ с подсветкой и статистикой. Настройки и списки слов лежат в пакете `config` и подхватываются при старте.

Условная схема потока:

```
Пользователь (Telegram)
        │
        ▼
  app/bot/handlers.py  ← команды, кнопки, текст
        │
        ▼
  app/analyzer/analyzer.py  ← токены, морфология, подсветка
        │
        ▼
  Ответ в чат (Markdown)
```

Модуль `app/analyzer/llm_yandex.py` в этот поток **не входит**: это заготовка для вызова API Yandex Cloud (тест/эксперимент), не подключённая к основному сценарию бота.

## ⚙️ Настройка бан-слов

Список задаётся в `backend/app/config/config.py` в переменной `TARGET_WORDS`. Для неоднозначных слов можно править словарь лемм `WORDS_LEMMA` (чтобы pymorphy3 не «ломал» нужную нормальную форму).

Пример:

```python
TARGET_WORDS = ["нейронка", "ваше_слово", "другое_слово"]
```

## Модули и ответственность

### Пакеты

- **`app/config`** — настройки бота: токен из окружения, список целевых слов, словарь лемм для особых случаев, лимит длины текста, базовая настройка логирования.
- **`app/analyzer`** — работа с текстом вне Telegram: разбиение на слова, морфология, поиск совпадений с бан-листом, подсветка и статистика. Отдельный файл `llm_yandex.py` — заготовка/тест вызова Yandex Cloud API, не используется основным потоком бота.
- **`app/bot`** — всё, что связано с Telegram: создание приложения, регистрация команд и обработчиков, ответы пользователю и вызов анализатора.

### Модули

1. **`app/bot/bot.py`** — точка входа процесса бота: загрузка `.env`, создание приложения, регистрация обработчиков команд (`/start`, `/help`, `/words`), кнопок и текстовых сообщений, глобального обработчика ошибок, запуск long polling.

2. **`app/bot/handlers.py`** — интерфейс с пользователем: приветствие и справка, список слов, клавиатура, извлечение текста или caption из сообщения, проверка длины, вызов анализатора, отправка текста с подсветкой, логирование и сообщения об ошибках.

3. **`app/analyzer/analyzer.py`** — класс `TextAnalyzer`: нормализация слова (кэш, словарь `WORDS_LEMMA`, pymorphy3), проверка «относится ли токен к целевому слову», обход всего текста с помощью `razdel` (разделяет слово на токены), сбор совпадений, подстановка `_курсив_` для Telegram Markdown, подсчёт `total`/`unique` и статистики по нормальным формам. Внизу модуля создаётся общий экземпляр `analyzer`.

4. **`app/analyzer/llm_yandex.py`** — заготовка/тест: клиент OpenAI-совместимого API Yandex Cloud, один демонстрационный запрос. Не импортируется из `bot` и не участвует в обработке сообщений, пока не будет встроен в продуктовый сценарий.

5. **`app/config/config.py`** — чтение `TELEGRAM_TOKEN` и при необходимости других переменных, константы `TARGET_WORDS`, `WORDS_LEMMA`, `MAX_TEXT_LENGTH`, настройка `logger` для всего приложения.

## 🔧 Стек

- **Python 3.9+** - основной язык
- **python-telegram-bot** - работа с Telegram API
- **python-dotenv** - переменные окружения из `.env`
- **pymorphy3** - морфологический анализ русского языка
- **razdel** - токенизация русского текста (границы слов для подсветки)
