# Yatъ

Текстовый редактор для веба: выделяет банворды, поддерживает Markdown и использует нейронки для редактуры.

## 📋 Что умеет бот v1.0

✅ **Анализирует текст** - находит целевые слова и их формы  
✅ **Выделяет слова _курсивом_** - показывает результат прямо в Telegram  
✅ **Работает с морфологией** - ищет все падежи и формы (нейронка, нейронки, нейронкой)  
✅ **Показывает статистику** (пока отключено) - сколько и каких слов найдено  
✅ **Игнорирует схожие слова** - "нейросети" ≠ "нейронка"  

## 🎯 Пример работы

**Сообщение:**
```
Современные нейронки используют сложные алгоритмы. 
Нейронка - это мощный инструмент для разработки.
```

**Ответ от бота:**
```
Современные **нейронки** используют сложные **алгоритмы**. 
**Нейронка** - это мощный инструмент для разработки.

📊 Статистика:
• нейронка: 2
• алгоритм: 1

Всего найдено: 3 слов
Уникальных слов: 2
```

## ⚙️ Настройка бан-слов

Они лежат файл `config.py`:
```python
TARGET_WORDS = ["нейронка", "ваше_слово", "другое_слово"]
```
