## Why

Бот сейчас только находит банворды, но не умеет исправлять ошибки текста — а это первый пункт дорожной карты. Заготовка `llm_yandex.py` существует, но не подключена к потоку и даже не рабочая. Нужен гибридный корректор (алгоритм + LLM), который станет самостоятельным ядром: в тг-боте для теста и на будущем вебе.

## What Changes

- Новый модуль коррекции `app/analyzer/corrector.py`: алгоритмический этап (явные опечатки, пробелы после знаков препинания, двойные пробелы, заглавная после точки) + опциональный глубокий этап через LLM (грамматика, пунктуация).
- Переписанный LLM-клиент Yandex Cloud вместо текущей заготовки: асинхронный класс, корректный endpoint/метод, добавление зависимости `openai`.
- Порог глубокой правки: текст ≤ 1000 символов — полный гибрид; длиннее — только алгоритм.
- Глубокая правка управляется переключателем (команда `/correct`), дефолт задаётся константой в конфиге (для прода — авто-вкл).
- Кэш результатов коррекции по хэшу текста (in-memory) — повторные сообщения не жгут лимиты LLM.
- Банворды (`TARGET_WORDS` + `WORDS_LEMMA`) попадают в белый список алгоритма — корректор их не «исправляет».
- Бот отвечает исправленным текстом с подсветкой банвордов; статистика — отдельным сообщением (структуры не смешиваются).
- При недоступности LLM или превышении порога — правка только алгоритмом + пометка «глубокая правка недоступна».

## Capabilities

### New Capabilities
- `text-correction`: гибридное исправление орфографии, грамматики и пунктуации — алгоритмический этап, глубокий этап LLM, пороги, кэш, недоступность глубокой правки. Клиент-агностик: не зависит от Telegram.
- `telegram-bot`: поведение бота как клиента коррекции — команда-переключатель `/correct`, поток ответов (исправленный текст + статистика отдельными сообщениями), длина текста и fallback-сообщения.

### Modified Capabilities
- (нет — существующих спеков в проекте нет)

## Impact

- **Новый файл**: `backend/app/analyzer/corrector.py` — алгоритм правок + оркестрация с LLM + кэш.
- **Переписка**: `backend/app/analyzer/llm_yandex.py` — асинхронный клиент Yandex Cloud (класс, корректный base_url и метод API).
- **Изменения**: `backend/app/bot/handlers.py` (вызов коррекции, `/correct`, поток сообщений), `backend/app/bot/bot.py` (регистрация команды), `backend/app/config/config.py` (новые константы: порог, дефолт переключателя, настройки LLM).
- **Зависимости**: добавить `openai` в `backend/requirements.txt`.
- **Без изменений**: `backend/app/analyzer/analyzer.py` — подсветка банвордов остаётся как есть, просто вызывается по исправленному тексту.
